Installation

Trois étapes

  1. Lance l'installeur

    Mac : double-clique sur Installer Flip (Mac).command. Si macOS le bloque : clic droit, Ouvrir, Ouvrir.
    Windows : Installer Flip (Windows).bat.

  2. Redémarre After Effects

    Puis ouvre Fenêtre > Extensions > Flip. Le panneau peut se ranger avec les autres.

  3. Convertis

    Sélectionne ta compo, choisis le format de sortie et clique sur Convertir. Tout s'annule avec Cmd/Ctrl + Z.

Ce que fait Flip

Pensé pour les vrais projets

Rien n'est coupé

Chaque bloc est calé dans sa case. Ce qui sortait du cadre d'origine reste caché, rien ne se superpose.

Ton original reste intact

Flip travaille sur une copie de la compo et de ses précomps.

Précomps, Nulls, caches

Les groupes parentés et les caches de suivi bougent ensemble ; les précomps plein écran sont converties aussi.

Scènes 3D

Les calques 3D ne bougent pas : la caméra est recentrée et les fonds s'agrandissent pour couvrir le cadre.

Plus de bandes noires

Les fonds remplissent tout le nouveau format par défaut.

Facile à retoucher

Ajuste à la main en déplaçant les calques « Flip · bloc » ajoutés dans la copie.

Ton retour

Teste-le sur tes projets

C'est une bêta. Pour qu'on corrige vite, envoie-nous :

  • ta version d'After Effects et ton système (Mac ou Windows) ;
